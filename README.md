# GLASS CHAT — Starter UI

This is a Flutter starter project for the proposed cross-platform messenger.
It includes a glass-inspired dashboard mockup with chat, gaming stats, group flags,
and color-coded rank/play-time tiers. It is a **UI prototype**, not a live messaging service.

## Included
- Dark glassmorphism-inspired dashboard
- Chat, gaming profile, groups and flag showcase
- Color-coded rank and play-time tiers
- Sample Lion-and-Sun flag card (illustrative)
- Responsive layout for phone and desktop widths

## Run
1. Install Flutter SDK from the official Flutter website.
2. In this folder, run `flutter create .`
3. Replace the generated `lib/main.dart` with this project's `lib/main.dart` if needed.
4. Run `flutter run -d windows` for Windows, or `flutter run` with an Android device/emulator.

## Not implemented yet
Real account registration/authentication, server/database, live chat, calls, verified play-time
integrations, payments, push notifications, end-to-end encryption, and production security.
These require backend services and testing before public release.
